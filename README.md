# What-Is-The-Color 🎨

Um projeto básico em **JavaScript** para demonstrar manipulação de cores.

---

## 📝 Descrição

Este repositório contém um projeto simples que explora cores usando JavaScript.  
Ele mostra como converter valores, manipular entrada do usuário e atualizar visualmente elementos na página conforme a cor escolhida.

É ideal para quem está começando a aprender manipulação de **DOM**, **eventos** e **lógica de cores** em JavaScript.

---

## 🚀 Tecnologias usadas

- HTML  
- CSS  
- JavaScript  

---

## 📂 Estrutura do projeto

| Arquivo       | Descrição |
|---------------|-----------|
| `index.html`  | Página principal com interface para escolher cores |
| `index2.html` | Segunda variante da interface |
| `style.css`   | Estilos visuais para a página |
| `hexa.js`     | Funções de manipulação de cores em HEX |
| `app.js`      | Script principal que controla o comportamento da aplicação |
